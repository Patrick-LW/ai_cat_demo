## 环境依赖
1.需要安装[Ollama](https:///olla,a.com/)客户端软件并保持后台运行。

2.拉取模型：
```bash
ollama pull qwen2.5:1.5b
```

3.Python环境依赖:
```bash
pip install -r requirements.txt
```
